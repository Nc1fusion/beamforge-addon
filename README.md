# beamforge-addon

Onglet **BEAMFORGE** pour BeamCutSoft (Visual Components 4.2). Complète Beamcut Soft sans le modifier.
Ce dépôt ne contient que le code de l'onglet : aucune donnée d'atelier.

## Première installation (une seule fois, sur le PC de l'atelier)
1. Télécharger : https://github.com/Nc1fusion/beamforge-addon/archive/refs/heads/main.zip
2. Extraire, puis copier `Mettre_a_jour_beamforge.bat` sur le bureau.
3. Fermer BeamCutSoft, double-cliquer `Mettre_a_jour_beamforge.bat`, rouvrir BeamCutSoft.

## Mises à jour
Fermer BeamCutSoft → double-cliquer `Mettre_a_jour_beamforge.bat` → rouvrir BeamCutSoft.
Les réglages (`config.ini`) sont conservés. La version installée s'affiche à la fin et dans **Diagnostic**.

## Désinstallation
Supprimer `C:\Users\Public\Documents\BeamCut\BeamCutSoft\My Commands\beamforge` et redémarrer BeamCutSoft.
